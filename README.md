# 🎱 Magic 8-Ball

Ask a yes/no question and let the ball decide.

A self-contained [MyOS](https://github.com/TechLab-JD/MyOS) app: HTML + CSS + a vanilla-JS ES module, no build step, no dependencies. Runs offline and stores anything it keeps in your browser.

## Use in MyOS
Add it as a submodule under `apps/` and register it in `data/modules.json`.
